# Security

Report a vulnerability privately: use "Report a vulnerability" under this repo's Security tab. Do not open a public issue for it.

Never post an API key, a broker key or a `.env` file, in an issue, a pull request or a log. If one leaks, revoke it at once (Allocait app, Settings > Agents, or your broker's dashboard) and create a new one.

This example places orders only when a person says yes, and defaults to paper and dry runs. A way around either is a security problem; report it.
